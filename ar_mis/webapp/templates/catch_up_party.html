Catch Up a Party — {{ branch.branch_name }}

For a party wrongly excluded from Sundry Debtors in Tally (misclassified group, or never onboarded) - a real balance you supply once, plus that party's real voucher history since then, pulled straight from Tally and run through the same reconciliation every other party gets. Not a typed-in closing figure: sales, receipts, credit notes and write-offs are each picked up correctly, because this uses the same process as a normal weekly run.

Before you use this

  1. Fix the ledger's group in Tally first (e.g. Sundry Creditor → Sundry Debtor). This tool cannot do that for you, and it will refuse below if it still can't find the party under Sundry Debtors.
  2. Open that ledger in Tally and read off its balance as of some past date you're confident in - the day before the earliest activity you want this tool to pick up.
  3. This is only for a party with NO extraction history yet. If it already has weekly data on record, use a logged adjustment instead.
