Before you save

  • Exact match only, once saved. Every name below must match a Tally voucher type name exactly (case/whitespace-insensitive) - no partial or substring matching anymore. This is deliberate: it's what stops a voucher type like "Proforma Sales" from being wrongly counted as a real "Sales" just because it contains that word.
  • Every category needs at least one real name. A category saved with none means this app will never capture that voucher type again for this branch - silently, since there'd be nothing left to match against. The form below won't let you save a blank category.
  • Each row is pre-filled with either what you've already saved here, or - if you've never set this up - the names the old global list already matches today, as a safe starting point. Change only what's actually different in your Tally.
  • If your Tally later adds a new voucher type name (a new series, a renamed type), add it here - it does not get picked up automatically.
